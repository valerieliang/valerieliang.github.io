RFI Mitigation for the NISAR Satellite Mission

Radio frequency interference detection and mitigation for NISAR Level-0 data, built at SURF@JPL 2026. A two-branch CNN learns the eigenvalue cutoff per tile instead of using a fixed one, so heavily contaminated tiles get cleaned properly and bright urban scatterers survive rather than being discarded as interference.

Causal Intervention Analysis of Coconut LLM

Steering vector experiments for the Coconut LLM. Extracts and analyzes steering vectors using contrastive pair methods (swap and cross-pair) to push latent reasoning trajectories around, and evaluates how superposition affects question answering.

Monte Carlo EKF-SLAM Simulator

Active EKF-SLAM simulator for exploring unknown 2D environments. The robot builds a feature-based map with an Extended Kalman Filter and picks where to go next by Monte Carlo sampling driven by its own positional uncertainty and expected information gain.
